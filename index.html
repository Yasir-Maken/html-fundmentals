The Basic Language of the Web: HTML

Posted by Laura Jones on Monday, June 21st 2027

All modern websites & web applications are built using three fundamental technologies: html, css, javascript. These are the languages of the web.

What is HTML?

HTML stands for HyperText Markup Language. It's a markup language that web developers use to structure and describe the content of a webpage (Not a Programming Language)

HTML consists of elements that describe different of content: paragraphes, links, headings, images, videos, etc. Web browsers understand HTML, and render HTML code as a website

In HTML, each element is made up of 3 parts

  1. The opening tag
  2. The closing tag
  3. The actual element

You can learn more at MDN Web Docs.

Why should you Learn HTML?

There are countless reasons for learning the fundamental language of the web. Here are 5 of them

  • To be able to use the fundamental web dev language
  • To hand-craft beautiful websites instead of relying of tools like worpress or wix
  • To build web applications
  • To impress friends
  • To have fun 😃
